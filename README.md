# Rajvision Portfolio

Personal portfolio of Rohit Raj, an Informatics student focused on software
engineering, Laravel backend development, applied machine learning, and
user-centered digital products.

Live website: https://rajvision.netlify.app/

## Featured work

- MediLabs — Laravel clinical laboratory reservation system
- Hematology ML Analysis — Random Forest and XGBoost research
- Planora — student productivity web application
- AI Painting Style Classification
- Parking Management App
- Luxyer Studio

## Technology

- React and TypeScript
- Three.js and WebGL
- GSAP
- Vite
- CSS

## Run locally

```bash
npm ci
npm run dev
```

Production build:

```bash
npm run build
```

## Project structure

```text
src/config.ts            Portfolio content and project data
src/components/          Homepage sections and 3D experience
src/pages/MyWorks.tsx    Complete selected-project listing
public/images/           Optimized portfolio imagery
public/documents/        Resume files
```

## Deployment

The repository includes a Netlify configuration for the Vite build, SPA route
fallback, caching, and baseline security headers.
